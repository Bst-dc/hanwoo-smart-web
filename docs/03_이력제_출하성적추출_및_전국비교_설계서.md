# [설계서 03] 이력제 출하성적 추출 및 전국 성적 비교분석 설계서

## 1. 개요
농가의 한우 출하성적을 손쉽게 수집하기 위해 **두 가지 입력 경로(OpenAPI 실시간 조회, 엑셀 일괄 업로드)**를 지원하며,
추출된 성적을 최신 축평원/KOSIS 전국 통계 벤치마크와 1:1로 비교하여 **성적 격차 및 경제적 손익 임팩트**를 자동으로 계산합니다.

---

## 2. 출하성적 추출 파이프라인

### 2.1 경로 A: 축평원(ekape) OpenAPI 연동
- **단계 1**: 사용자가 농가의 개체이력번호(12자리) 목록을 텍스트 영역에 붙여넣기 (쉼표 또는 줄바꿈 구분).
- **단계 2**: 개체번호로 등급판정확인서 발급번호(`issueNo`) 조회:
  ```
  GET http://data.ekape.or.kr/openapi-data/service/user/grade/confirm/issueNo?animalNo={animalNo}&ServiceKey={API_KEY}
  ```
- **단계 3**: 발급번호로 소 등급판정 상세 데이터 조회:
  ```
  GET http://data.ekape.or.kr/openapi-data/service/user/grade/confirm/cattle?issueNo={issueNo}&ServiceKey={API_KEY}
  ```
- **단계 4**: 반환된 XML에서 다음 핵심 지표를 추출하여 DB에 저장:
  - 도체중(`weight`), 육질등급(`qgrade`), 육량등급(`wgrade`), 근내지방도(`insfat`), 등지방두께(`backfat`), 배최장근단면적(`rea`), 출하월령(`birthmonth`), 경락단가(`costAmt`)
- **캐싱(Cache)**: 이미 조회된 개체는 `api_cache.json` 또는 로컬 DB에 저장하여 중복 API 호출 방지 및 고속 처리.

### 2.2 경로 B: 엑셀 일괄 업로드 파서
- 축평원 출하성적 엑셀, 농가 출하내역서 등 엑셀 파일(`.xlsx`)을 드래그앤드롭으로 업로드.
- 헤더 자동 매핑 알고리즘:
  - 이력번호 컬럼: `이력번호`, `개체번호`, `개체식별번호`
  - 도축일자: `도축일자`, `출하일자` (연도 추출)
  - 성별: `성별`, `구분` (거세, 암 정규화)
  - 도체중: `도체중`, `도체중량`
  - 등급: `육질등급`, `육량등급`
  - 도체품질: `근내지방도`, `BMS`, `등지방두께`, `등심단면적`, `도축개월령`

### 4.2 경제성(수익성) 격차 산출 공식
- **단가 기준**: 음성공판장 2025년 평균 경락단가
  - `1++`: 23,038원/kg, `1+`: 19,590원/kg, `1`: 18,165원/kg, `2`: 14,969원/kg, `3`: 12,735원/kg
- **추정 손익 공식**:
  $$\text{두당 수익 격차} = (\text{농가 도체중} \times \text{농가 평균단가}) - (\text{전국 도체중} \times \text{전국 평균단가})$$
  $$\text{농가 연간 총 손익 임팩트} = \text{두당 수익 격차} \times \text{연간 출하 두수}$$
- 이를 통해 **"1+ 이상 출현율 6.3%p 개선 시 연간 약 850만 원 추가 수익 가능"**과 같은 구체적 기대효과 수치를 산출합니다.
