# [설계서 06] 누적 통계 대시보드 및 전체 농가 평균 성적 분석 설계서

## 1. 개요
본 모듈은 시스템에 등록되고 방문한 모든 농가의 데이터를 취합하여,
**"내가 지금까지 몇 농가를 방문했는가?", "방문한 농가 전체의 연도별 평균 성적은 어떻게 변화하고 있는가?", "전국 평균과 비교했을 때 우리 관할 농가들의 수준은 어떠한가?"**를 한눈에 파악할 수 있는 통합 대시보드를 제공합니다.

---

## 2. 대시보드 주요 구성 화면

### 2.1 상단: 핵심 성과 지표 (KPI Cards)
```
┌───────────────┐ ┌───────────────┐ ┌───────────────┐ ┌───────────────┐
│  총 관리 농가  │ │  누적 방문 횟수│ │ 누적 분석 두수│ │전체 1+이상 출현율│
│     42 농가   │ │     98 회     │ │   3,450 두    │ │    72.8 %     │
│ (전월 대비 +3)│ │ (이번 달 12회)│ │ (거세 2,800두)│ │(전국대비 +1.5%p)│
└───────────────┘ └───────────────┘ └───────────────┘ └───────────────┘
```

### 2.2 중앙 1: 3차원 벤치마크 연도별 성적 비교 차트 (Chart.js)
동일한 그래프 상에 3개의 라인을 겹쳐 표시하여 트렌드를 직관적으로 비교합니다:
1. **전국 평균 성적** (축평원 KOSIS 통계 기준)
2. **지금까지 방문한 전체 농가 평균 성적** (DB 누적 집계값)
3. **현재 선택된 농가 성적** (특정 농가 컨설팅 시)

**제공 지표 탭**:
- [도체중(kg)] [근내지방도(BMS)] [등지방두께(mm)] [등심단면적(㎠)] [1+이상 출현율(%)]

### 2.3 중앙 2: 연도별 종합 성적 요약 매트릭스 테이블
| 연도 | 구분 | 방문농가수 | 출하두수 | 평균 도체중 | 평균 BMS | 1+이상 비율 | 전국 도체중 | 전국 BMS | 전국 1+비율 |

### 2.4 하단: 농가별 랭킹 및 최근 컨설팅 활동 타임라인
- **성적 우수 농가 TOP 5**: BMS 순위, 도체중 순위, 1++ 출현율 순위.
- **최근 컨설팅 방문 이력**: 농가명, 방문일시, 방문차수, AI 리포트 바로가기 버튼, 상태(완료).

## 3. 데이터 집계 및 캐싱 아키텍처
- 통계 쿼리 속도 최적화를 위해, 신규 출하성적이 입력되거나 현장 조사가 완료될 때 `shipment_summaries` 테이블에 연도별 요약이 사전 계산(Pre-aggregation)되어 적재됩니다.
- 대시보드 진입 시 단 0.05초 만에 전체 농가의 연도별 평균 데이터가 로딩되어 사용자 대기 시간을 최소화합니다.
- 전체 데이터는 언제든지 **엑셀(.xlsx) 또는 CSV로 원클릭 백업 다운로드**가 가능합니다.
