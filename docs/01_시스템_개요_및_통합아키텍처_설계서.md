# [설계서 01] 한우 스마트 컨설팅 통합 웹 플랫폼 아키텍처 설계서

## 1. 프로젝트 개요

### 1.1 배경 및 목적
- 한우 컨설팅 현장에서 농가의 출하성적(정량 데이터)과 사양관리 실태(정성 데이터)를 분리 관리하던 한계를 극복.
- 축산물이력제/축산물품질평가원(ekape) API를 통해 개체별 출하 성적을 원클릭으로 추출하고 전국 통계와 1:1 비교.
- 모바일/태블릿으로 현장 방문 정보를 즉시 기록하고, Claude AI를 통해 **"진단 → 원인 → 처방 → 액션플랜"**의 전문 리포트를 자동 발행.
- 모든 컨설팅 데이터(출하성적, 비교표, 현장조사, AI리포트)를 SQLite 데이터베이스에 영구 누적하여, 방문 농가 수 및 전체 연도별 평균 성적 추이를 실시간 대시보드로 시각화.

### 1.2 핵심 사용자 워크플로우 (5+2단계)
```
[1단계] 이력제 입력/엑셀 업로드 ──▶ 출하성적(도체중, BMS, 등급, 월령) 자동 추출
        │
[2단계] 전국 벤치마크 비교 ──▶ 축평원/KOSIS 전국 평균 대비 격차 및 수익성 임팩트 산출
        │
[3단계] 농가 현장 방문 ──▶ 모바일/태블릿으로 사양관리·시설환경·농가대화 현장 정보 수집
        │
[4단계] 현장 데이터 입력 ──▶ 터치식 체크리스트, 평점, 음성/메모 텍스트 즉시 저장
        │
[5단계] Claude AI 종합 분석 ──▶ "진단-원인-처방" 7단 구성 맞춤형 리포트 자동 생성
        │
[6단계] 자동 누적 DB화 ──▶ 농가별/방문차수별 영구 DB 적재 (SQLite/PostgreSQL)
        │
[7단계] 통계 대시보드 ──▶ 총 방문 농가수, 누적 평균 성적, 연도별 트렌드 비교
```

## 2. 시스템 아키텍처

### 2.1 전체 구조도
```
┌────────────────────────────────────────────────────────────────────────┐
│                          클라이언트 레이어                              │
│   ┌─────────────────────┐   ┌─────────────────────┐                    │
│   │    PC 관리/분석      │   │  모바일/태블릿 현장   │                    │
│   │  (대시보드·심층리포트) │   │ (사양조사·대화입력)  │                    │
│   └─────────────────────┘   └─────────────────────┘                    │
│                 반응형 웹 UI (HTML5, Vanilla CSS, JS)                   │
└────────────────────────────────────────────────────────────────────────┘
                                  ▲
                                  │ HTTP / JSON
                                  ▼
┌────────────────────────────────────────────────────────────────────────┐
│                        백엔드 애플리케이션 레이어                       │
│  ┌──────────────────────────────────────────────────────────────────┐  │
│  │                    FastAPI / Python Web Core                     │  │
│  │  - /api/farms        : 농가 등록 및 이력 관리                      │  │
│  │  - /api/shipments    : 이력제 API 조회 & 엑셀 파싱 & 전국비교       │  │
│  │  - /api/surveys      : 현장 사양관리 조사표 CRUD                   │  │
│  │  - /api/claude       : Claude API 종합 리포트 생성 엔진            │  │
│  │  - /api/dashboard    : 누적 방문 통계 & 연도별 평균 성적 집계       │  │
│  └──────────────────────────────────────────────────────────────────┘  │
└────────────────────────────────────────────────────────────────────────┘
         │                       │                      │
         ▼                       ▼                      ▼
┌──────────────────┐    ┌──────────────────┐   ┌────────────────────────┐
│   로컬 누적 DB    │    │   외부 연동 API   │   │     Claude AI Core     │
│   (SQLite File)  │    │ - ekape (축평원) │   │ - claude-sonnet        │
│ consulting.db    │    │ - KOSIS (통계청) │   │ - 맞춤형 7단 리포트 생성 │
└──────────────────┘    └──────────────────┘   └────────────────────────┘
```

### 2.2 기술 스택 선정 근거
| 구분 | 기술 스택 | 선정 이유 |
| :--- | :--- | :--- |
| **백엔드** | Python 3.10+ & FastAPI | 파이썬 생태계(Pandas, OpenPyXL 등) 활용 극대화, 비동기 ekape API 통신 지원, 경량 및 고성능 |
| **프론트엔드** | Modern Vanilla HTML/CSS/JS + Chart.js | 의존성 최소화(npm 빌드 불필요), 모바일 브라우저 최적화, 구글 드라이브 동기화 폴더에서도 즉각 실행 가능 |
| **데이터베이스** | SQLite 3 (단일 파일 DB) | 파일 1개(`consulting.db`)로 모든 농가/성적/리포트가 누적 보관되어 구글 드라이브 백업 및 이동이 완벽함 |
| **AI 엔진** | Anthropic Claude API (Sonnet) | 축산 전문 도메인 지식 이해도 최고, 진단-원인-처방 1:1 논리적 매칭 리포트 작성 탁월 |
| **외부 API** | 축평원 ekape 등급판정확인서 API + KOSIS 통계 API | 100% 공공 실시간 데이터 기반 신뢰성 확보 |
