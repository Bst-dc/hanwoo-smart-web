# [설계서 05] Claude AI 분석 엔진 및 프롬프트 설계서

## 1. 개요
본 모듈은 농가의 **정량 출하성적(전국 대비 결손 지표)**과 **정성 현장조사 데이터(사양관리 미흡점 및 농가 대화 내용)**를 융합하여,
Anthropic Claude API(`claude-sonnet`)를 통해 수의학 및 사양관리 전문성에 기반한 **"진단 → 원인 → 처방 → 로드맵"** 맞춤형 컨설팅 리포트를 자동 생성합니다.

---

## 2. 데이터 전처리 및 프롬프트 파이프라인

```
┌────────────────────────┐      ┌────────────────────────┐

│ - 도체중, BMS, 등지방   │      │ - 사료급여량, TMR, 환기 │
```

## 3. 프롬프트 상세 설계

### 3.1 시스템 프롬프트 (System Prompt)
```text
당신은 대한민국 최고의 한우 사양관리 최고전문가(수석 컨설턴트)입니다.
농가의 최근 3개년 출하성적(도체중, BMS, 등지방두께, 등심단면적, 출하월령) 정량 데이터와
현장 방문에서 수집된 사양관리 실태, 축사 환경, 농가와의 심층 대화 정성 데이터를 융합 분석하여,
농장주가 즉각 실행할 수 있는 "진단 → 원인 → 처방"의 논리적 흐름을 갖춘 맞춤형 컨설팅 보고서를 작성하세요.

[원칙]
1. 정량적 수치와 현장 사양관리 문제점을 1:1로 정확하게 매칭하세요.
   (예: 등지방이 두껍고 BMS가 낮은 원인 ──▶ 비육중기 배합사료 과다 급여 및 육성기 조사료 부족)
2. 추상적인 조언 대신 구체적인 수치(kg, 개월령, 사료비율, 환기시간 등)를 처방에 명시하세요.
3. 경제적 손익 임팩트(연간 예상 손실액 및 개선 시 기대 수익)를 함께 제시하세요.
```

### 3.2 사용자 프롬프트 템플릿 (User Prompt Template)
```markdown
[농가 기본정보]
- 농가명: {farmer_name} (대표: {owner_name})
- 사육형태: {breeding_type} / 사육두수: {total_heads}두
- 조사일자: {visit_date} / 방문회차: {visit_number}회차 / 컨설턴트: {consultant_name}

[1. 최근 출하성적 vs 전국 평균 비교 데이터]
{shipment_comparison_json}

[2. 현장 실태조사 및 농가 대화 데이터]
- 성장단계별 사료급여: {feed_data_json}
- 축사 시설 및 사육환경: {facility_data_json}
- 질병 및 번식관리: {health_data_json}
- 농가 대화 내용 및 핵심 고민사항:
  "{farmer_dialogue}"
- 현장 관찰 컨설턴트 소견:
  "{consultant_memo}"

[보고서 작성 필수 7단 구성 가이드]
다음 목차와 양식에 맞추어 깔끔한 마크다운(Markdown)으로 보고서를 작성해주세요:

# 1. 종합 컨설팅 요약 배너
농가명, 방문일시, 컨설턴트, 핵심 평가 등급 제시.

# 2. 핵심 진단 요약 (30초 요약 카드)
출하성적과 현장 대화에서 발견된 가장 시급한 3가지 핵심 이슈를 카드로 제시.

# 3. 출하성적 전국 비교 및 수익성 임팩트
거세/암 연도별 성적 비교표 제시 및 전국 대비 격차 분석, 두당/연간 수익 격차 환산.

# 4. 현장 사양관리 실태 진단
육성기~비육후기 사료 급여 프로그램과 축사 환경의 적정성을 [양호 / 보통 / 미흡] 배지로 판정.

# 5. 핵심 문제별 원인 분석 및 개선 처방 (1:1 매칭)
현장 문제점마다 [문제 현상] → [근본 원인] → [정밀 처방]의 3단 구조로 구체적인 솔루션 제시.

# 6. 실행 우선순위 로드맵 (Action Plan)
- 1단계 (즉시 조치 / 1~2주): 사료 급여량 조절, 환풍기 타이머 설정 등
- 2단계 (기반 구축 / 1~3개월): TMR 배합비 수정, 깔짚 관리 주기 개선
- 3단계 (성적 개선 / 6개월~출하): 출하월령 단축, 1++ 등급 출현율 극대화

# 7. 참고 매뉴얼 및 안내 사항
농촌진흥청 국립축산과학원 사양표준 인용 및 실행 전 담당 축협 컨설턴트 협의 권장 면책 문구.
```

## 4. 리포트 출력 및 저장 파이프라인
1. Claude API에서 반환된 스트리밍 마크다운을 브라우저에 실시간 렌더링.
2. `ai_reports` 테이블에 마크다운 원문 및 핵심 진단 텍스트를 영구 저장.
3. 브라우저 인쇄(`window.print()`)를 통해 표준 A4 규격의 고품질 PDF 보고서로 즉시 출력/다운로드 지원.
