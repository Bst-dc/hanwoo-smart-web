# [설계서 04] 모바일 현장정보 수집 UI/UX 설계서

## 1. 개요 및 디자인 원칙

현장 컨설팅 환경(우사 현장, 야외, 장갑 착용 가능성 등)을 고려하여 스마트폰 및 태블릿에 최적화된 모바일 친화적 입력 인터페이스를 제공합니다.

### 핵심 디자인 원칙
1. **엄지손가락 친화적 (Thumb-friendly)**: 핵심 선택 버튼(양호/보통/미흡)은 최소 48px 이상의 대형 터치 타깃 제공.
2. **빠른 세그먼트 버튼 (Segmented Controls)**: 타이핑을 최소화하고 탭(클릭) 한 번으로 상태 평가 완료.
3. **음성 인식(STT) 지원**: 농가와의 대화나 현장 관찰 소견을 타이핑하지 않고 음성으로 말하면 즉시 텍스트로 변환.
4. **오프라인 로컬 저장 (Local Storage)**: 통신이 불안정한 축사 현장에서도 입력 내용이 날아가지 않고 브라우저에 임시 저장된 후 연결 복구 시 자동 동기화.

## 2. 화면 구성 및 입력 섹션

### 2.1 상단: 농가 및 방문 메타 정보
- 농가 선택 드롭다운 또는 검색 입력
- 방문 일자 (기본값: 오늘 날짜) 및 방문 회차 (N차 자동 계산)
- 컨설턴트 이름, 현재 사육두수(번식우/비육우)

### 2.2 섹션 1: 성장단계별 정밀 사양관리 실태
각 단계별 **사료 종류(TMR/배합사료), 1일 급여량(체중 대비 %), 조사료 급여 형태, 상태 배지(양호/보통/미흡)**를 빠르게 탭:
- **육성기 (생후 ~13개월)**: 조사료 무제한 여부, 배합사료 1.6~1.8% 제한 여부
- **비육전기 (14~18개월)**: 배합사료 2.5% 수준 여부, TMR 섭취량
- **비육중기 (19~24개월)**: 배합사료 2.0% 정밀 통제 여부 (과비 방지)
- **비육후기 (25개월~출하)**: 고열량 사료 집중 급여 여부, 비타민 제한/보충

### 2.3 섹션 2: 축사 시설 및 사육 환경 평가
- **우방 밀도**: 두당 면적 (10㎡ 이상 확보 여부) → [적정 / 보통 / 과밀]
- **환기 및 공기질**: 환풍기 가동, 암모니아 가스 냄새, 결로 → [양호 / 보통 / 불량]
- **바닥 깔짚 상태**: 깔짚 건조도, 교체 주기, 분변 고임 → [건조·양호 / 보통 / 다습·불량]
- **급수 시설**: 급수조 청결도, 보온 급수 여부, 수압 → [청결 / 보통 / 오염]

### 2.4 섹션 3: 질병 및 번식 관리
- **송아지 질병**: 설사/호흡기 발생 빈도, 초유 급여 시간, 로코백 접종 여부
- **비육우 대사성 질환**: 요결석, 과산증, 제엽염, 버짐(피부병) 발생 여부 체크
- **번식우 (해당 시)**: 수태율(%), 분만 간격(개월), 인공수정 위생 관리

### 2.5 섹션 4: 농가 대화 내용 및 현장 사진
- **농장주 애로사항 및 목표 (대화 기록)**:
  - 🎤 [음성 입력] 버튼 제공 (브라우저 Web Speech API 연동)
  - 예: "작년보다 도체중이 20kg 줄었다고 고민하심. 조사료 수급이 어려워 볏짚 위주로 바꾼 영향으로 추정됨."
- **컨설턴트 현장 총평**:
  - 현장에서 바로 느낀 핵심 개선점 2~3줄 요약.
- **현장 사진 첨부**:
  - 모바일 카메라로 즉시 촬영 또는 갤러리 업로드 (우사 상태, 사료 상태, 소 외관 등).
